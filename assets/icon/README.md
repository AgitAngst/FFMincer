# Значок FFMincer

Две стрелки «вперёд» (FF — fast forward и ffmpeg) на розовой плитке: целая впереди, нарезанная на ломтики позади —
след скорости и «фарш». Ломтики расходятся назад и бледнеют (прозрачность 0,32 → 0,88), целая стрелка белая, плитка —
градиент `#F26A83 → #C4325A` (розовый — цвет программы в семье Anvil). Выбор владельца 29.09.2026 (вариант «Всё белое»).

| Файл | Что это |
|---|---|
| `ffmincer.svg` | Полный значок: четыре ломтика, стрелки 300 × 504. Источник для 64 px и крупнее |
| `ffmincer-small.svg` | Для мелких размеров: три ломтика, зазор 28. Источник для 16–48 px |
| `ffmincer-{16,24,32,48}.png` | Из `ffmincer-small.svg` |
| `ffmincer-{64,128,256,512}.png` | Из `ffmincer.svg` |
| `ffmincer.ico` | Кадры PNG 16, 24, 32, 48, 64, 128, 256 — значок exe |

PNG и `.ico` не правятся руками — их собирает одна команда из SVG (нужен `resvg`, `scoop install resvg`):

```powershell
powershell -File scripts\render-icon.ps1
```

Повторный запуск без правок SVG даёт те же файлы.

**Где значок используется.** Значок exe — `ffmincer.ico` (`build.rs`, `winresource`); значок окна и панели задач —
`ffmincer-256.png`, которую `build.rs` превращает в сырые пиксели (`src/icon.rs`); знак в шапке и в «О программе»
рисуется кодом (`src/mark.rs`) по геометрии `ffmincer-small.svg` — цвета от темы окна не зависят.

**Центровка.** Целая стрелка тяжелее бледного следа, поэтому по границам знак кажется сдвинутым вправо, а по яркой
части — влево. Взято по центру массы с небольшим уклоном к яркой стрелке: сдвиг записан в `transform` группы знака
(−12, −8) для полного и (6, −8) для мелкого, в единицах 1024.
