# FFMincer 🥩

Простой конвертер аудио и видео с GUI на Rust (egui) поверх `ffmpeg`.
Кидаешь файлы в очередь — на выходе готовый "фарш" в нужном формате.

## Возможности

- Drag-and-drop файлов в окно
- Очередь конвертации с прогресс-баром по каждому файлу
- Быстрые пресеты: MP4 (CPU), MP4 (NVENC), MKV (H.265), MP3, FLAC
- Тонкая настройка кодека, CRF/битрейта, preset, разрешения
- Аппаратное декодирование через CUDA (NVIDIA)
- Нормализация громкости (loudnorm), быстрый старт mp4 (faststart), сохранение метаданных
- Шаблон имени результата, папка вывода, что делать по завершении очереди (открыть папку, сон, выключение)
- Никогда не перезаписывает исходный файл
- Светлая и тёмная темы, английский и русский — «⚙ → Настройки» (Ctrl+,); настройки — в
  `%APPDATA%\FFMincer\config.txt`
- Сам узнаёт о новых версиях на GitHub и обновляется из окна (с проверкой SHA-256); выключается в настройках

Вид и обновления — общие для программ семьи [Anvil](https://github.com/AgitAngst/Anvil) (`anvil-ui`,
`anvil-update`).

## Требования

- `ffmpeg` и `ffprobe` в PATH или путь к ним в настройках (там же — тихая установка через winget)
- Rust (стабильный тулчейн)

## Сборка

```bash
cargo build --release
```

Бинарник появится в `target/release/ffmincer` (или `ffmincer.exe` на Windows).

## Запуск

```bash
cargo run --release
```

## Выпуск

Тег `vX.Y.Z` (лучше из мастера выпуска Anvil): workflow `release.yml` соберёт
`ffmincer-X.Y.Z-windows-x64.zip` с `SHA256SUMS` и опубликует GitHub Release.
